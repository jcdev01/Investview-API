EXPLICAÇÃO DO GRAFO — INVESTVIEW-API
====================================

O grafo representa quais ativos os investidores costumam ter juntos na
carteira de favoritos. Ele é construído a partir dos favoritos de TODOS os
usuários, mas sem expor quem favoritou o quê — só dados agregados.


VÉRTICE (NÓ)
------------
É um ativo que aparece em pelo menos um favorito. O identificador é
"TYPE:SYMBOL" (ex.: STOCK:PETR4, CRYPTO:BTC), e ele carrega symbol, type
(STOCK/FII/ETF/CRYPTO) e name (nome de exibição, se alguém cadastrou).
Se ninguém favoritar nada, o grafo fica vazio.


ARESTA
------
É a conexão entre dois ativos que foram favoritados PELO MESMO USUÁRIO.
Não é direcionada: PETR4-VALE3 é a mesma aresta de VALE3-PETR4.
Ex.: Alice favorita PETR4 e VALE3 -> cria a aresta entre elas.
Como um usuário com 5 favoritos gera todos os pares possíveis (10 arestas),
quem tem carteira parecida com outra pessoa vai reforçando as mesmas
conexões.


PESO
----
A "força" da conexão: quantos usuários distintos têm os dois ativos juntos.
Alice sozinha -> peso 1; Bob também favorita os dois -> peso 2.
É a métrica de "popularidade do par": quanto maior o peso, mais gente
costuma combinar aqueles dois ativos.


VIZINHO
-------
Um ativo diretamente conectado a outro por uma aresta. Os vizinhos de
STOCK:PETR4 são todos os ativos que aparecem na carteira de alguém junto
com PETR4 — ordenados por peso decrescente no endpoint /neighbors,
ou seja, "quem mais anda junto com PETR4".


GRAU
----
Quantidade de vizinhos de um nó. Ativo com grau alto = presente em muitas
carteiras variadas.


CAMINHO (E MENOR CAMINHO)
-------------------------
Sequência de arestas ligando dois ativos. O endpoint /graph/path usa BFS
(busca em largura) para achar o caminho com MENOR NÚMERO DE SALTOS
(ignora pesos). Se Alice tem PETR4+VALE3 e Bob tem VALE3+BTC, o caminho
PETR4->BTC é [PETR4, VALE3, BTC] com length: 2, mesmo PETR4 e BTC nunca
tendo aparecido juntos para a mesma pessoa. Se não houver ligação nenhuma,
retorna found: false.


COMPONENTE CONEXO
-----------------
"Ilha" de ativos conectados entre si, sem ponte com o resto. Serve para
identificar clusters/perfis de carteira (ex.: um cluster de criptos,
outro de ações brasileiras). Ativo favoritado por só um usuário que não
favorita mais nada forma um componente isolado (nó sem arestas).


RESUMO EM UMA FRASE
-------------------
O nó é o ativo, a aresta é "alguém tem os dois juntos", o peso é
"quantos alguém têm", vizinho é o que anda junto, caminho é a ligação
indireta e componente é o grupo/cluster.
